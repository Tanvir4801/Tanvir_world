# Visual Identity and Design Guidelines

This document outlines the visual rules that govern the "Tanvir's World" portfolio. The Design Agent enforces these rules.

## Aesthetic Pillars
- **Apple-Inspired**: Smooth curves, subtle shadows, native-feeling UI components.
- **Premium & Minimal**: Embrace whitespace. Avoid clutter. Less is more.
- **Technical & Elegant**: Code snippets and architecture diagrams should look beautiful.
- **Human-Designed**: Avoid generic AI-generated aesthetics (e.g., standard neon, random cyberpunk elements, floating abstract cubes that lack context).

## Color Palette
*(To be defined during implementation, but generally)*
- Dark mode default to emphasize the screen and lighting.
- Deep grays, stark whites for text.
- Accent colors should be purposeful (e.g., blue for links/selection, specific brand colors for projects).

## Typography
- **Primary**: Inter, SF Pro, or similar modern sans-serif for UI elements.
- **Monospace**: Roboto Mono, Fira Code, or JetBrains Mono for the Terminal and VS Code environments.
- Maintain high contrast for readability.

## Interaction & Motion
- Use subtle micro-interactions on hover (scale, slight color shift, shadow changes).
- 3D motion (camera parallax on mousemove) must be smooth and not induce motion sickness.
- Transition from 3D to 2D OS must feel intentional and seamless.
